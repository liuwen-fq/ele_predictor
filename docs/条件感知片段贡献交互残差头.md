# 条件感知片段贡献—交互解释头（无 fidelity 版本）

## 目的与使用原则

该版本将“高精度预测”和“片段归因”拆成两个输出：Bamboo-Mixer FT 主线负责最终
电导率预测；独立的解释头负责用可加和的片段项重现实验电导率。解释头**不会**反向
修改 Bamboo 的预测。

```text
最终预测：conductivity_pred = conductivity_base_pred

解释预测：conductivity_explain
        = 条件基准 q(盐组成、盐浓度、温度)
        + 溶剂片段主贡献之和
        + 跨溶剂分子片段对交互之和
```

因此，`conductivity_pred` 应用于筛选和报告最终预测精度；
`conductivity_explain_pred` 用于验证片段分解是否能重现实验趋势，并用于片段、
官能团、溶剂和片段对归因。二者不要求数值相同。

## 与旧“残差加入预测”设计的区别

| 项目 | 旧贡献残差头 | 当前无 fidelity 解释头 |
| --- | --- | --- |
| 片段项的去向 | 加到 Bamboo 电导率预测 | 只组成独立解释预测 |
| Bamboo 主线 | 可能受片段残差影响 | 完全冻结，输出严格保持 |
| 片段头监督 | 通过最终预测间接拟合 | 直接拟合实验电导率 |
| fidelity 约束 | 不适用或与基线残差绑定 | 不使用 `conductivity_explain_fidelity_MAE` |
| 解释含义 | 对 Bamboo 预测的修正 | 给定条件下的配方组成关联解释 |

取消 fidelity 的原因是：原版 Bamboo 的少数经验公式输出可出现很大的偏离，使用
`|conductivity_explain - conductivity_base|` 会主导 loss，并压制解释头对实验电导率
和片段效应的学习。无 fidelity 版本只以实验标签监督解释头，同时保留少量片段正则化。

## 模型结构

### 1. 固定的分子与片段表示

分子主路径来自原版 Bamboo mono checkpoint。FragmentBlock 使用 `mode: sidecar`，
只读取原子/键表示并产生冻结的片段向量 `f_j`，不把片段信号写回原子、键或 Bamboo
分子表示：

```text
原子/键表示
    ↓
固定 FragmentBlock：片段编码、片段连接消息传递、片段 attention pooling
    ↓
每个溶剂分子的片段向量 f_j
```

FragmentBlock 的分子级向量不参与 Bamboo 主路径融合；因此没有使用旧的
`h_molecule = h_base + gate × Projection(z_fragment)` 方案。

### 2. 条件基准与片段解释

条件向量由盐组成的 Bamboo 聚合表示、盐浓度和温度组成。线性条件基准给出在这些
条件下、不区分溶剂片段组成的电导率参考值 `q`。

对溶剂片段 `j`，解释头计算带正负号的主效应 `a_j`。片段 `j,k` 的交互效应 `b_jk`
使用低秩双线性交互，只保留来自**不同溶剂分子**的片段对：

```text
raw_residual = Σ_j a_j + Σ_(j,k; molecule(j) ≠ molecule(k)) b_jk
residual     = 0.2 × tanh(raw_residual / 0.2)
conductivity_explain = q + residual
```

每个片段的权重为：

```text
所属溶剂的摩尔比例 / 该溶剂的片段总数
```

这避免片段数量更多的分子仅因拆分更细而获得更大的总贡献。总片段效应有界在归一化
log 电导率空间的 `±0.2`；同一个公式级缩放同时应用于主贡献和交互贡献，所以：

```text
Σ_j 导出的主贡献 + Σ_jk 导出的交互贡献 = residual
```

加和关系严格成立。

盐、浓度和温度的总体影响由条件基准 `q` 吸收；当前导出的片段归因对象是溶剂片段，
不应把某个溶剂片段效应误读为“盐种效应”。

## 训练目标

训练只更新 `fragment_explanation_head.*`。Bamboo 分子主干、配方聚合器、经验电导率
readout、anion-ratio readout 和 FragmentBlock 全部固定。

训练损失为：

```text
L = 1.0 × MAE(conductivity_explain, 实验电导率)
  + 0.001 × L1(片段主贡献)
  + 0.002 × L1(片段对交互贡献)
  + 0.005 × L2(总片段残差)
```

其中没有 `conductivity_explain_fidelity_MAE`。主预测 `conductivity_pred` 不参与这个
解释头训练目标，也不接收解释头梯度。

## 运行

无 fidelity pipeline 使用独立目录，不会覆盖旧的带 fidelity 实验：

```bash
nohup env CUDA_VISIBLE_DEVICES=0 \
  bash submit/run_fragment_explanation_no_fidelity_pipeline.sh all \
  > run/fragment_explanation_no_fidelity_pipeline.out 2>&1 &
```

如果训练已完成而只需重新生成预测：

```bash
bash submit/run_fragment_explanation_no_fidelity_pipeline.sh predict
bash submit/run_fragment_explanation_no_fidelity_pipeline.sh explain
```

`explain` 阶段会同时生成基础汇总和通用的中文高/低电导率片段归因报告，后者位于
`run/fragment_explanation_no_fidelity/comprehensive_attribution/`。

相关文件：

- `config/train/fragment_formula_ft_explanation_no_fidelity.yaml`：训练配置；
- `config/test_results/fragment_predict_explanation_no_fidelity.yaml`：预测配置；
- `submit/run_fragment_explanation_no_fidelity_pipeline.sh`：一键 pipeline；
- `run/fragment_explanation_no_fidelity/results/ft_test_predictions.json`：逐配方预测与归因；
- `run/fragment_explanation_no_fidelity/explanations/`：官能团、溶剂和片段对汇总。

## 当前 FT test 结果

在 1,561 个有实验电导率标签的 FT test 样本上：

| 输出 | MAE (mS/cm) | RMSE (mS/cm) | R² | log conductivity MAE |
| --- | ---: | ---: | ---: | ---: |
| Bamboo 最终预测 `conductivity_pred` | 0.1686 | 0.4555 | 0.9888 | 0.0614 |
| 可加和解释预测 `conductivity_explain_pred` | 0.4265 | 1.6539 | 0.8525 | 0.1478 |

解释头弱于 Bamboo 主线是正常结果：Bamboo 可以利用完整、非线性的配方表征；解释头
被约束为“条件基准 + 可加和片段项 + 两两交互”，主动舍弃了不能可靠分配给片段的高阶
信息。`R²=0.8525` 说明该受约束的分解仍可重现实验电导率的大部分变化，因此可用于
模型内结构归因；它不应替代 Bamboo 主线作为最终预测器。

## 输出字段与解释方法

每个配方的 JSON 中：

- `conductivity_pred`：最终采用的 Bamboo 物理电导率预测；
- `conductivity_base_pred`：与 `conductivity_pred` 严格相同，用于显式核验；
- `conductivity_explain_pred`：由条件基准和片段项相加后、再反归一化得到的解释预测；
- `fragment_explanations.condition_reference_normalized`：条件基准 `q`；
- 每个溶剂片段的 `conductivity_main_effect_normalized`：片段相对于同一条件基准的主贡献；
- `fragment_explanations.main_effect_sum_normalized`：所有片段主贡献之和；
- `fragment_explanations.interaction_sum_normalized`：所有跨分子片段对贡献之和；
- `fragment_explanations.top_fragment_pairs`：片段对及其有符号交互贡献。

正主贡献表示该片段使解释头的预测值高于相同盐、浓度、温度下的条件基准；负贡献
表示降低该解释值。正交互表示该对溶剂片段在当前配方条件下呈正协同关联，负交互
表示负协同/拮抗关联。

Fragment attention 仅用于片段池化，并不是电导率方向贡献；高 attention 不等价于提高
电导率，也不等价于重要的正片段贡献。

## 归因报告的使用边界

推荐从 `explanations/` 中的下列文件开始：

- `functional_group_signed_contributions.csv`：官能团层面的正负贡献；
- `solvent_candidate_summary.csv`：候选溶剂的出现频率、高低电导率富集和累计效应；
- `fragment_pair_signed_interactions.csv`：跨溶剂分子的片段对交互；
- `interpretation_report.md`：自动生成的汇总说明。

只报告同时满足以下条件的候选项：在多个配方中重复出现、贡献方向稳定、不是由极少数
样本驱动，并在保持盐、浓度、温度和配比可比的替换实验中得到支持。模型中的“提高”、
“降低”、“协同”和“拮抗”是条件关联与模型归因结论，不能直接等同于未经验证的化学
因果结论。
