# 实验测试集片段解释流程

该流程使用 `predict.py` 输出 JSON 中的 `fragment_attention`，对实验电导率测试集生成可追溯的片段注意力分析。它不重新训练模型，也不需要 GPU。

## 运行

在 `ele_predictor` 目录执行（默认分析当前 sidecar 的实验测试集结果）：

```bash
bash analysis/run_fragment_analysis.sh
```

也可以传入任意 `predict.py` 生成的预测 JSON 和目标输出目录：

```bash
bash analysis/run_fragment_analysis.sh \
  run/fragment_sidecar/results/ft_test_predictions.json \
  analysis/fragment_sidecar_explanations_v2
```

可使用环境变量调整分位数、代表案例数和最低支持度，例如：

```bash
MIN_GROUP_FORMULAS=20 MIN_PAIR_FORMULAS=20 QUANTILE=0.2 bash analysis/run_fragment_analysis.sh
```

## 输出文件

- `analysis_summary.json`：样本数量、分组阈值和分析配置。
- `case_explanations.json`：每个实验测试配方的真实值、预测值、溶剂比例、原始片段 SMILES、去氢规范 SMILES、带 `*` 连接点的 SMILES、互斥主功能团、原子索引、连接关系，以及注意力衍生指标。
- `representative_cases.json`：低电导率和高电导率的准确预测案例，以及最大低估、最大高估案例。
- `fragment_attention_summary.csv`：仅对多片段分子统计的连接点片段明细，含连接点 SMILES 和片段化学式；不包含 attention 恒为 1 的完整分子单片段。
- `functional_group_summary.csv`：同一配方内同类功能团合并后的全局统计，含代表性 SMILES 与化学式，是报告主表的数据来源。
- `functional_group_high_low_association.csv`：按功能团比较实验电导率最高和最低分位组的注意力差异；未出现时按 0 计入组均值。
- `functional_group_high_low_composition.csv`：按功能团是否出现在配方中比较高、低电导率组的出现率和优势比，包含完整分子单片段。
- `functional_group_pair_coordination.csv`：功能团对在高、低电导率组中的共现统计及相对共现比，用于筛选配方协调或低电导率共现候选。
- `whole_molecule_fragments.csv`：无法进行分子内 attention 比较的完整分子单片段，单独列出且不参与功能团排名。
- `interpretation_report.md`：可直接阅读的统计摘要，主表和高低组关联表均显示代表性 SMILES 与片段化学式。

## 指标含义

每个中性溶剂内的 `pooling_attention` 之和为 1，只能在同一个分子内部比较。

- `attention_enrichment = pooling_attention * 片段数`：大于 1 表示高于该分子内均匀分配基线。
- `formula_weighted_attention = pooling_attention * 溶剂摩尔比例`：兼顾片段在分子内的关注度和该溶剂在配方中的占比。

`neutral_only: true` 时，带电盐/阴离子的片段不会注入编码器表示。流程会保留其结构信息，但不会把它们纳入统计解释。

功能团使用最具体类别优先的互斥规则，例如“环状碳酸酯 > 内酯 > 碳酸酯 > 酯基 > 醚键”。单片段分子的 attention 必然等于 1，因此不会进入功能团 attention 排名。

报告默认只显示至少出现在 10 个实验配方中的功能团。可通过 `MIN_GROUP_FORMULAS` 修改：

```bash
MIN_GROUP_FORMULAS=20 bash submit/fragment_explanation_pipeline.sh
```

## 解释边界

当前结果是注意力分析，不是片段对电导率的因果贡献。高低电导率分组也会受到温度、盐浓度、盐种和共溶剂的共同影响。

后续应增加片段消融：保持配方和条件不变，遮蔽一个片段后重新预测，报告 `Delta log(conductivity)`。高低组富集和共现统计同样只是候选筛选，只有当高 attention 片段的消融效应显著大于低 attention 或随机片段时，才可以将其称为可靠的电导率归因。
