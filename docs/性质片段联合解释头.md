# 条件感知的性质—片段联合解释头

## 模型边界

该头不会修改 Bamboo FT 的部署预测：

```text
conductivity_pred = conductivity_base_pred
```

它单独拟合实验电导率的受约束解释：

```text
conductivity_explain =
条件基准 q(盐种、浓度、温度)
+ 溶剂性质贡献 P(dc、vis、Tm)
+ 片段主贡献 M
+ 跨溶剂片段对交互 I
```

其中 `M + I` 是有界片段残差，仍严格满足：

```text
Σ 片段主贡献 + Σ 片段对交互 = 片段残差
```

性质贡献也按溶剂摩尔比例汇总，并以同一配方级缩放保持：

```text
Σ 溶剂的 dc / vis / Tm 贡献 = 配方性质贡献
```

## 为什么首批使用 dc、vis、Tm

- `dc`：盐解离与自由离子比例的主要线索；
- `vis`：离子迁移率与扩散阻力的主要线索；
- `Tm`：低温液态范围、结晶风险和输运可行性的辅助线索。

这些值来自冻结分子多任务模型，并在各配方的实际温度下重新计算。它们在 JSON 中首先以模型归一化尺度导出；物理单位应以单体性质预测的独立校准结果或实验测量为准。

## 训练目标

```text
MAE(conductivity_explain, experimental conductivity)
+ 性质贡献 L1
+ 片段主贡献 L1
+ 片段对交互 L1
+ 片段残差 L2
```

不使用 Bamboo fidelity 约束。原因是解释头要重现实验电导率趋势；同时 Bamboo 主预测被冻结，因此解释头的拟合误差不会降低最终预测精度。

## 使用注意

正/负性质贡献表示模型在给定盐种、浓度、温度和配方组成下的条件关联。例如正 `dc` 项并不单独证明“提高介电常数必然提高电导率”；该效应可能与黏度、离子配位及盐浓度共同变化。
